## Known provisional items (carried over from the handoffs)

**Stage 1-2**
- Regime multipliers, transition matrix, Hawkes parameters, tick value and proxy loadings are illustrative, not calibrated.
- Regimes only partly express (realised stressed/calm alpha ratio 1.49x vs 2.5x long-run).
- Stage 2 defaults not tuned (2000 particles per bank, `jump_prob = 0.03`, `obs_noise_inflation = 1.0`); the filter knows the true regime model; Gaussian likelihood on core channels only, hence biased and overconfident on spread-Hawkes.

**Stage 3**
- Primary metric (validation-selected checkpoint) was fixed after the oracle's final-checkpoint metric failed; report both metrics.
- 5 training seeds per arm: contrast se is 4-12 $, so only effects above about 12-27 $ are detectable. 14 paired contrasts examined, about 0.7 chance positives expected.
- Fresh-world scores re-score the same trained agents on new worlds; they are not independent replications over training seeds.
- The ensemble idea arose after results were seen; not pre-registered. One ensemble per arm, so inference is over worlds only; 5x inference cost. `filt_full_bonus` was picked as best after seeing results.
- Hawkes: 4 arms only (no K = 1, no-regime or bonus arms); no seed-level contrasts; seeds 3-4 added after seeing the 3-seed results. Unexplained: the raw_proxy ensemble is far better on Hawkes than on Gaussian (-70.8 vs -45.9 $, test), which shrinks the filtered-vs-raw gap; do not interpret without a Hawkes contrast run.
- The exploration bonus is a heuristic (only beta = 1.0 run). Network and hyperparameters untuned; no claim of matching Macri and Lillo (2025).
- Cached beliefs rely on world/proxy/belief independence from the agent's actions, verified for Gaussian and Hawkes.

**Stage 4**
- BL is a first-order approximation that underperforms TWAP here; damped-BL rows are exploratory (damping chosen on the same worlds). Test thresholds in `test_bl_consistency.py` were set after seeing output.
- CE is a reference, not the optimum (non-causal ceiling about -194 $). It uses the TRUE state and true parameters, so agent-vs-CE gaps mix agent quality with filter noise; true-parameter CE is optimistic, mainly through theta.
- 200-world and 500-world numbers must not be mixed (the first 200 fresh worlds are 4-7 $ harder for every policy). The heuristic's oracle mean is unstable across world sets (+4.0 vs +50.6): never quote it as one number.
- SHAP describes how this filter reacts, one step at a time, not causal informativeness or what the agents use; one filter seed; shares come with large interaction terms.
- Live particle count: agents trained and scored at 2000; the check script's live runs use 500; the dashboard backend ran at the 2000 default (no particle note shown).
- Optional extensions not done: Hawkes `ens_contrasts`, paired ensemble-vs-CE on the 500-world blocks, simulated CE misspecification, rereading the Barger-Lorig paper's printed formula, dueling head / n-step returns / soft target updates.
